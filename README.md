# Utifix Lab

A responsive starter homepage for an all-in-one online tools website, built with Next.js and ready for Vercel deployment.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Visit `http://localhost:3000`.

## Deploy to Vercel

1. Create a GitHub account if you don't already have one.
2. Create a new GitHub repository and upload the contents of this folder.
3. Sign in to Vercel using GitHub.
4. Choose **Add New → Project**, import the `utifix-lab` repository.
5. Keep the detected Next.js settings and click **Deploy**.

## Important

This is the first homepage prototype. Search and category filters work. Tool cards are currently a UI catalogue; the individual PDF, image, SEO, calculator and AI tools still need to be implemented and connected in later steps.
